# Data Structures & Algorithms 1 (DSA1) Repositories

This meta-repository manages all starter (`[assignment]`) and solution (`[assignment]-solution`) repository pairs for the Data Structures & Algorithms 1 (DSA1) course as Git submodules.

## Managed Sub-repositories

### Labs
- [`dsa1-lab-hello`](dsa1-lab-hello) / [`dsa1-lab-hello-solution`](dsa1-lab-hello-solution): Hello World Environment & GitHub Classroom Onboarding

### Checkpoints
- [`dsa1-checkpoint-card-deck`](dsa1-checkpoint-card-deck) / [`dsa1-checkpoint-card-deck-solution`](dsa1-checkpoint-card-deck-solution): Card Deck Management & Array Manipulation
- [`dsa1-checkpoint-rational-number`](dsa1-checkpoint-rational-number) / [`dsa1-checkpoint-rational-number-solution`](dsa1-checkpoint-rational-number-solution): Rational Number Class & Operator Overloading
- [`dsa1-checkpoint-room-simulator`](dsa1-checkpoint-room-simulator) / [`dsa1-checkpoint-room-simulator-solution`](dsa1-checkpoint-room-simulator-solution): Room Simulator & Class Hierarchy
- [`dsa1-checkpoint-wildfire`](dsa1-checkpoint-wildfire) / [`dsa1-checkpoint-wildfire-solution`](dsa1-checkpoint-wildfire-solution): Wildfire Simulation & Grid Operations

### Projects
- [`dsa1-proj-big-int`](dsa1-proj-big-int) / [`dsa1-proj-big-int-solution`](dsa1-proj-big-int-solution): Arbitrary Precision Integer Arithmetic
- [`dsa1-proj-filesystem`](dsa1-proj-filesystem) / [`dsa1-proj-filesystem-solution`](dsa1-proj-filesystem-solution): In-Memory File System Simulation

- [`dsa1-proj-minesweeper`](dsa1-proj-minesweeper) / [`dsa1-proj-minesweeper-solution`](dsa1-proj-minesweeper-solution): Command-Line Minesweeper Game Engine
- [`dsa1-proj-morbidity-data`](dsa1-proj-morbidity-data) / [`dsa1-proj-morbidity-data-solution`](dsa1-proj-morbidity-data-solution): Morbidity & Public Health Data Analysis
- [`dsa1-proj-password-manager`](dsa1-proj-password-manager) / [`dsa1-proj-password-manager-solution`](dsa1-proj-password-manager-solution): Encrypted Command-Line Password Manager
